# GoreeCloud Mesh Branding Contract

## Branding authority

GoreeCloud Mesh branding is governed by the unified GoreeCloud branding repository:

- Repository: `GoreeCloud/goreecloud-branding-assets`
- System path: `systems/goreecloud-mesh/`
- Presentation surface: Mesh Center

## Current artwork status

No approved canonical GoreeCloud Mesh logo, icon, or artwork exists yet.

Until an exact Mesh identity is explicitly approved and committed in `GoreeCloud/goreecloud-branding-assets`, Mesh must use text-only identity presentation where a system identity treatment is required. Do not create or promote a generic mesh/network glyph, inherited GoreeCloud logo, application icon, placeholder, or automatically generated mark as the official Mesh identity.

## Future identity workflow

1. Create and review Mesh identity candidates in the unified branding repository.
2. Record explicit approval for the exact selected source.
3. Promote the approved source under `systems/goreecloud-mesh/`.
4. Only then synchronize required derivatives into this repository, Mesh Center, documentation, packaging, or other consumers.
5. Keep all consumer copies traceable to the unified canonical asset.

## Authority boundary

GoreeCloud Mesh is the substantive coordination and governance plane connecting first-party applications, services, and systems. Branding does not create service authority, interoperability, evidence validity, Stable acceptance, or production readiness. Those claims remain governed by Mesh implementation and current authoritative evidence.
